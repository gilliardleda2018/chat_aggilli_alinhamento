## Requisitos

- Python 3.10+
- FFmpeg instalado e no PATH
- Tkinter (incluído no Python)
- requests, Pillow (opcionais)

## Instalação

1. Clone este repositório
2. Instale dependências: `pip install requests Pillow`
3. Execute o `.bat` da versão desejada
